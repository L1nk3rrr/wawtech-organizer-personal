# WAWTech 2026 · План на два дні

Мобільний маршрут для Odoo-розробника, який упроваджує AI у компанії. Відвідувач може зберегти рекомендований день або зібрати свій план із каталогу. Закладки, нотатки та підсумки зберігаються в браузері й переносяться через експорт та імпорт JSON.

[Відкрити GitHub Pages](https://l1nk3rrr.github.io/wawtech-organizer-personal/)

## Запуск і публікація

- Локально: `python3 -m http.server 8080 --directory docs` і відкрити `http://localhost:8080/`.
- GitHub Pages: джерело **Deploy from a branch** → **main** → **/docs**. Сайт складається зі статичних файлів.
- Відкрий сайт з інтернетом і дочекайся статусу готовності до офлайн-режиму внизу сторінки. Зовнішні карти, календар і сайти потребують мережі.

## Дані

- `docs/agenda.js` містить знімок офіційної програми на 25 листопада. Пошук працює за українськими назвами, іменами, компаніями, темами й сценами.
- `docs/route.js` містить добірку для Odoo + AI, перерви, запитання та практичні висновки.
- Під час оновлення розкладу зберігай існуючі ID сесій. Збільшуй номер кешу в `docs/sw.js` зі змінами сайту. Нова версія офлайн-кешу активується після закриття вкладок зі старою версією.
- Час локальний для Варшави. У картках використовуються назви сцен із програми. Розташування залів уточнюється на місці.
